# 🎬 Small Movie Ticket Booking System (Java Swing + SQLite)

A Desktop-based Movie Ticket Booking Application built using **Java Swing** for the Graphical User Interface (GUI) and **SQLite** for persistent local database storage.

---

## 📌 Features

- **Interactive User Interface (GUI):** Built with Java Swing for a seamless booking experience.
- **Real-Time Seat Selection:** Dynamic dropdown menu showing only available seats.
- **SQLite Database Integration:** Saves user booking details locally in `movie_booking.db`.
- **Database Synchronization:** Automatically syncs booked seats on application startup to prevent double booking.
- **Input Validation:** Alert messages for empty fields and double booking attempts.

---

## 🛠️ Tech Stack & Requirements

- **Language:** Java (JDK 8 or higher)
- **GUI Framework:** Java Swing
- **Database:** SQLite
- **JDBC Driver:** `sqlite-jdbc-0.00.0.0.jar` (or compatible version)
